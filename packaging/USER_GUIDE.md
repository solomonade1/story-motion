#### Check your download (optional, about one minute)

This proves the file is complete and unchanged. Skip it if you trust where you got the file.

1. Open the folder that holds the zip (usually **Downloads**).
2. Click the address bar at the top of the File Explorer window, type `powershell` and press **Enter**. A blue window opens.

### Install in 5 steps

There is no installer. "Installing" means unpacking the zip into a folder you keep.

1. **Download** the zip (see above). You should see `StoryMotion-Studio-0.1.0-win64.zip` in your **Downloads** folder.
2. **Unblock the zip.** Right-click the zip, choose **Properties**. At the bottom of the **General** tab, if you see a **Security** line with a tick box **Unblock**, tick it and click **OK**. If there is no such box, carry on. You should see the Properties window close.
3. **Extract everything.** Right-click the zip and choose **Extract All...** (on Windows 11: **Show more options**, then **Extract All...** if you do not see it at once). Choose a short, simple place such as `C:\Apps` or your **Documents** folder, then click **Extract**. Wait a minute or two. You should see a new folder called `StoryMotion-Studio-0.1.0-win64` that contains files such as `StoryMotion Studio.vbs`, `USER GUIDE.md` and folders called `python`, `app` and `licenses`.
   Do **not** run anything from inside the zip, and avoid very deep or very long folder names.
4. **Start the app.** Open the new folder and double-click **`StoryMotion Studio.vbs`**. (It may show as **StoryMotion Studio** with a "VBScript" file type.) Nothing flashes and there is no black console window. After a few seconds, a window titled **StoryMotion Studio** opens with the heading **Welcome to StoryMotion Studio**.
5. **Add a shortcut (optional).** Double-click **`Add Desktop Shortcut.vbs`**. A message says a shortcut was added to your Desktop. From now on, double-click **StoryMotion Studio** on your Desktop.

#### If Windows warns you

The download is not "code-signed" (signing is a paid certificate), so Windows may be careful the first time. This is expected.

| What you see | What it means | What to do |
|---|---|---|
| **Windows protected your PC** (blue SmartScreen box) | Windows does not recognise the publisher | Click **More info**, then **Run anyway**. Only do this for a file you downloaded from the official Releases page |
| A security warning that says the file came from another computer, or "Open File - Security Warning" | The zip was not unblocked | Click **Run** or **Open**. Next time, do step 2 (Unblock) before extracting |
| Extracted files still ask "Do you want to run this file?" | The zip was extracted before it was unblocked | Delete the extracted folder, unblock the zip (step 2), extract again |
| A message that an application control policy or **Smart App Control** blocked a file | Smart App Control (an optional Windows 11 protection) only allows signed programs, and the bundled video tool `ffmpeg.exe` is not signed by Microsoft | See "Troubleshooting": "Smart App Control blocked a file" |

### First run walkthrough

The first screen is the **Setup check**. It tests your computer and tells you in plain words what works.

1. After step 4 above, the window shows **Welcome to StoryMotion Studio**, a line saying everything runs on this computer, and the heading **Setup check**.
2. Wait for **Checking this computer...** to finish. You then see a list. Each line has a coloured label:

   | Label | Meaning |
   |---|---|
   | **Ready** | This works |
   | **Optional** | Not needed. For example **Piper voice (optional)** is normally "not installed": the app then uses the built-in Windows voice. That is fine |
   | **Needs attention** | Something must be fixed. The line shows **How to fix** |

3. The checks are **Python worker**, **FFmpeg + ffprobe**, **Workspace folder**, **Free disk space**, **Piper voice (optional)** and **Offline mode**.

6. You arrive at **Your projects**. You can reach the **Setup check** again at any time with the **Setup check** button at the top right.


**Closing the app:** close its window with the normal **X**. This also stops the program behind it. If an import or render is running, the window asks you first.


## Make your first video

This is a start-to-finish walkthrough. Allow an hour for your first video. Every button name is shown in **bold**, exactly as it appears on screen.

**The idea in one minute.** You give StoryMotion a recorded **narration** (the voice), **pictures**, and optionally music and video clips. You split the story into **scenes**, and each scene into **shots**. A shot says "show this picture, from this second to that second, with this camera movement". StoryMotion then builds a finished MP4 video on your computer. The narration is the master clock: every shot is timed against it.

> The app does not decide timings for you. When you import a script, you get scenes but **no shots**. You add the shots and set how long each lasts. The app then checks your timing and tells you what to fix.

### Before you start: gather your files

| You need | Details |
|---|---|
| **Narration** (required) | One audio file: WAV, MP3 or AAC. This sets the length of the whole video |
| **Pictures** | PNG, JPG or WebP. Best: 16:9 shape, at least 1920 x 1080. Larger (for example 2560 x 1440) leaves room for slow zooms |
| **Script** (optional) | A plain text (`.txt`) or Markdown (`.md`) file. See Step 3 for how it is split into scenes |
| **Music or ambience** (optional) | WAV, MP3 or AAC. Make sure you have the right to use it |
| **Video clips** (optional) | MP4 or MOV, for shots a still picture cannot show. 1920 x 1080 at 24 frames per second works best |
| **Cut-outs for moving characters** (optional) | PNG pictures with a transparent background |

Other file types (for example `.m4a`, `.avi`, `.gif`, `.bmp`) are refused with a clear message. Convert them first, or choose a supported type.

**Your original files are never changed or moved.**

### Step 1. Create a project

1. Start the app (see "Download and install") and click **Continue** on the Setup check.
2. On **Your projects**, click **New project** (or **Create your first project** if the list is empty).
3. Type a **Project name**, for example `Jonah episode 1`, and click **Create**.
4. The project opens with three tabs: **Media**, **Storyboard** and **Script & notes**.

On **Your projects**, each project has **Open**, **Rename**, **Duplicate**, **Archive** and **Delete**. See "Where your files go" for what these do.


### Step 2. Import your files (the Media tab)

1. Click the **Media** tab. You see the **Add media** box.
2. Choose how to add the files:
   - **Copy into the project** (recommended): StoryMotion keeps its own copy, so the project still works if you later move or delete the originals.
   - **Link to the original**: nothing is copied; the project points to your file. If you later move the file, use **Relink...**.
3. Click **Browse...** and choose your files. A normal Windows file window opens; you can select many files at once (hold **Ctrl** or **Shift**). The paths appear in the box.
   - If there is no **Browse...** button, type the full path of each file, one per line, for example `C:\Users\You\Pictures\harbour.png`. Quote marks around a path are fine.
4. Click **Import**.
5. Watch **Activity**. Each file shows progress, then a summary such as "12 added", plus counts for files "already in the project" (duplicates are detected automatically) and files that "could not be imported", each with a reason.
6. Every imported file appears in the **Library** with a preview, size and length. A green **OK** label means it is fine.

Good to know:
- You can import up to 500 files at a time.
- The category menu under each file (character, environment, prop, audio, effect, and so on) is a label to help you keep things tidy. Your video does not depend on it.
- **Remove** takes a file out of the project. It does not delete your original.
- **Check files** re-checks that every file is still there and unchanged. Use it after moving or editing files. The result is reported as "Checked: x fine, y missing, z changed".
- The filter menu (**Everything**, a category, **Missing**, **Changed**) helps you find things in a big library.
- If a file goes **Missing** or **Changed**, a warning appears. Use **Relink...** on that file and give the new location of the same file, or click **Find moved files in a folder...** and choose a folder to search.


### Step 3. Import the script (optional but handy)

1. Click the **Storyboard** tab.
2. Click **Import script (.txt, .md)** and choose your script file.
3. StoryMotion splits it into scenes:
   - **Markdown (.md):** each heading that starts with `#`, `##` or `###` begins a new scene. The text under it is that scene's passage.
   - **Plain text (.txt):** each paragraph (separated by a blank line) is a scene. If the file has no blank lines, each line becomes a scene.
4. If the project already has scenes, a box asks **Replace the current storyboard?** Choose **Keep what I have** or **Replace it**. Nothing is replaced without asking. Your chosen narration and characters are kept.

You can also type or paste your script on the **Script & notes** tab. That text is kept with the project; it is not turned into scenes by itself.

Instead of a script, you can click **Import scene plan (.json)** to bring in a ready-made plan file, for example one that an AI assistant revised from your exported brief (see "Exporting"). The plan is checked before anything is accepted, and any problem is listed with where it is.


### Step 4. Choose the narration

1. At the top of the **Storyboard** tab, open the menu **Narration (the clock for every shot)** and choose your narration file. Its length is shown next to its name.
2. A line then reads **Narration length: ...**. All shot times are measured on this clock, in **milliseconds** (1000 ms = 1 second).

Optional: type a name next to **Add a character** and click **Add character** to list the people in your story. You can tick them on each shot later. This is for your own bookkeeping and for the AI brief; it does not change the picture.

### Step 5. Add and arrange shots

For each scene:

1. Click **Add shot to this scene**. A new shot appears (a STATIC shot of up to 3 seconds that starts where the last shot ended) and its editor opens near the bottom of the page.
2. In the editor, set:
   - **Picture**: choose one of your pictures.
   - **Duration (ms)**: how long the shot lasts. Example: `8000` is 8 seconds. **Start (ms)** is filled in for you.
   - **Animation mode**:

     | Mode | Use it for |
     |---|---|
     | **STATIC** | One picture that does not move |
     | **CINEMATIC** | One picture with a slow camera move (see **Motion preset**) |
     | **LAYERED** | A background picture plus separate transparent cut-outs that move (see below) |
     | **RENDERED** | A video clip you made elsewhere (choose it under **Video clip**) |
     | **GENERATIVE** | Not available in this version. The shot uses a plain local fallback and the app tells you so |

   - **Motion preset** (for CINEMATIC shots): `slow-push-in`, `slow-pull-out`, `pan-left`, `pan-right`, `reveal` or `hold` (no movement). STATIC shots stay still.
   - **Transition into this shot**: **Cut**, **Crossfade (dissolve)** or **Dip to black**, plus **Transition length (ms)**. The very first shot cannot have a transition; use **Video fade-in (ms)** (above the timeline) for that.
   - **Action**, **Must show (one per line)**, **Avoid (one per line)**: notes about what happens in the shot. They do not change the picture, but they travel with your exports and help any editor or AI that reads them.
3. Use the up and down arrow buttons next to each shot to move it inside its scene, and the arrows next to a scene title to move whole scenes. **Add scene** adds an empty scene. **Remove scene** removes one (you can **Undo** straight away).

More options:
- **RENDERED** shots also have **Trim start of clip (ms)** and **Clip speed** (normal, a few slower speeds, or **Slow to fit the shot**).
- **LAYERED** shots show **Moving layers (drawn back to front)**. Click **Add layer**, pick a transparent PNG as the **Layer picture**, and set where it starts and ends (position, size, tilt). A small stage preview and a slider show the movement. Layers are flat pictures: they can slide, grow, tilt and rock, but not bend.
- **Music and ambience** (above the timeline): click **Add music or ambience**, pick a file, set its **Level (dB)**, how much to lower it while the narrator speaks (**Lower under narration by (dB)**), its fades, and whether it repeats. Import the audio on the **Media** tab first.
- **Video fade-in (ms)** and **Video fade-out (ms)** fade the whole video from and to black.
- Every change is **saved automatically** a moment after you stop. The label in the corner reads **All changes saved** when it is done. Many removals show an **Undo** button.


### Step 6. Check the timing

The **Timeline** shows one block per shot along the narration, with a marker where the narration ends. Click a block to edit that shot. Drag the **Scrub** slider to see a still picture of the shot at that moment. This is only a quick look: it shows no motion, transitions or sound.

Under the timeline is the list **Timeline checks** (or the message **No timing problems found.**). Each item is labelled:

| Label | Meaning |
|---|---|
| **Problem** | Must be fixed before you can render (for example a picture was removed from the project) |
| **Check** | Usually must be fixed too: a gap or overlap between shots, shots that end well before or after the narration, a shot with no picture, a transition longer than its neighbours |
| **Note** | Information only |

Each item has a **Show** button that jumps to the shot. Two buttons fix the most common timing problems:

- **Close gaps and overlaps**: keeps the order and lengths, and makes each shot start when the previous one ends.
- **Fit last shot to narration end**: stretches the last shot so the video ends with the narration.

A reliable routine: set each shot's **Duration (ms)**, click **Close gaps and overlaps**, then **Fit last shot to narration end**, then clear whatever **Timeline checks** still lists. Small differences (up to 250 ms at the end) are tolerated.

The app refuses to render while serious items remain, and says exactly what to fix.

### Step 7. Render a draft

1. Scroll down to the **Render** area.
2. Click **Render draft**. A progress bar and percentage appear. You can click **Cancel render**; cancelling takes effect when the current step ends, and nothing is published.
3. When it finishes, the video appears in a player, labelled **Draft proxy: not final quality**. A draft is small (640 x 360) with a "DRAFT" badge. It is for checking timing, order and motion, not picture quality.
4. Press play. Fix anything you dislike, render another draft, and repeat.

Do not close the window while a render is running. The app warns you if you try.

### Step 8. Render the final video

1. When the draft looks right, click **Render final (full size)**.
2. Wait. A few minutes is normal for a 3 to 5 minute video, and longer on a slower computer. Each render builds the whole video again.
3. The result is labelled **Final export**. The app checks the finished file (streams, length, unplanned black frames) and reports its size, frame rate and any warnings.
4. Every render is a **new file**. Earlier drafts and finals are kept. Choose between them in the **Rendered videos** menu.

### Step 9. Find your finished video file

The finished MP4 files are stored inside your project folder. The app does not yet have a "show in folder" button for renders (it does for exports), so use this route:

1. Open File Explorer and go to `C:\Users\<your name>\StoryMotion Studio\projects`. (If you changed the workspace, use that folder instead.)
2. Open the folder whose name starts with `p-` and was changed most recently (click the **Date modified** column to sort). If you have several projects, open them one by one and look for a `renders` folder with your latest file.
3. Open the `renders` folder. Files ending in `-final.mp4` are final renders. Files ending in `-draft.mp4` are drafts. Each also has a small report file next to it.
4. **Copy** the final MP4 somewhere you will find it (Desktop, Videos, a USB drive). Copy rather than move, so the project keeps its history.

### What is not available yet

So you do not look for it:

- AI-generated video clips and any cloud service. The app works fully offline.
- Sound effects on individual shots, waveform editing, and dragging clip edges on the timeline.
- Depth (parallax) effects, and animation beyond a layer's start and end positions.
- An in-app voice recorder or voice generator: bring your own narration file.
- Opening old command-line "episode folders" as Studio projects.


## Exporting

Exporting packages your work for someone or something else: a video editor, a collaborator, or an AI assistant. **Nothing is uploaded.** An export is just a new folder on your own computer.

This is different from the finished video. To make the MP4, use **Render draft** and **Render final (full size)** (see "Make your first video"). Use **Export** when you want the separate pieces.

### How to export

1. Open your project and click the **Storyboard** tab.
2. Scroll to the **Export** area, below **Render**.
3. Click one of the three buttons:

   | Button | What you get | Use it when |
   |---|---|---|
   | **Export independent assets** | Plain files that need no editor and no StoryMotion: every shot as its own clip of exactly the right length (each with a small `.json` description and a poster picture), the narration, music and final mix as WAV audio, your original pictures and clips copied unchanged, an `index.json` list, and a `SHA256SUMS.txt` file of checksums | You want to keep or hand over everything in a simple, future-proof form |
   | **Export for editing** | One clip per shot (with a few extra frames so a following transition has room), the narration and each music bed as WAV, `final_mix.wav`, and the timeline as `timeline.otio` and `timeline.edl` | You want to fine-tune the cut in a video editor |
   | **Export brief for AI models** | A folder `ai` with `handoff.json` (every scene, shot, time, setting and problem), still pictures of each shot and contact sheets, the script, the storyboard format description, and `README_FOR_MODELS.md` with instructions for the assistant | You want an AI assistant to review your video or suggest a better storyboard |

4. Watch the progress bar. You can click **Cancel export**. When it is done a green message says how many shots and files were written and how big the export is.
5. Under it, the list **Exports** shows every export you have made. Click **Show folder** next to one to open it in File Explorer.


Exports are written under your project, in a folder called `exports`. Every export is new: earlier exports are kept. An editing export also contains a `README.md` that explains what is inside.

### Using the editing export

- **DaVinci Resolve 18.5 or newer:** use **File, Import, Timeline...** and choose `timeline.otio` (it is in the `timeline` folder). The clips and audio are in the `shots` and `audio` folders next to it.
- **Premiere Pro and other editors:** import `timeline.edl`. An EDL carries video only, and "dip to black" transitions are written as dissolves. Bring the audio in from `audio\final_mix.wav` (or the separate narration and music files).
- No editor? Open the `shots` folder and join the clips in any editor you like. Each clip is already trimmed to size.

> **Honest note:** these timeline files follow the published formats but have **not yet been tested in any video editor**. Treat your first import as a test. If something does not line up, you still have every clip and the full audio, so you lose nothing. Please report what happened.
> One test did pass: rebuilding a video from the exported clips, the timeline and `final_mix.wav` alone gave pictures identical to the app's own final render.

### Using the AI brief

1. Click **Export brief for AI models** and then **Show folder**.
2. Give an AI assistant the contents of the `ai` folder, starting with `README_FOR_MODELS.md`.
3. The assistant may answer with a revised storyboard (a `.json` file). Bring it back with **Import scene plan (.json)** on the **Storyboard** tab. It is checked first, and you are asked before anything is replaced.

**Privacy:** the brief contains your script text and still frames of your pictures. If you give it to an outside service, that is your choice and your service's rules apply. StoryMotion itself sends nothing anywhere.

### Checking an independent-assets export

`SHA256SUMS.txt` lists a fingerprint (checksum) for each file, so you can prove later that nothing was altered. To check one file, open PowerShell in that folder (click the File Explorer address bar, type `powershell`, press **Enter**) and run `Get-FileHash .\index.json -Algorithm SHA256`. The result should match the line for that file in `SHA256SUMS.txt`.


## Where your files go, backups, updating and uninstalling

### Where your files go

All your work is saved in one folder, called the **workspace**:

`C:\Users\<your name>\StoryMotion Studio`

The Setup check shows it next to **Workspace:**. You do not need to create it. It is **separate from the app folder**: deleting or replacing the app never touches your projects.

Inside the workspace:

| Item | What it is |
|---|---|
| `projects\p-xxxxxxxxxxxx\` | One folder per project (the name is a code, not your project name) |
| ...`\project.json` | The project itself: its name, script, notes and storyboard. A copy called `project.json.bak` is kept beside it |
| ...`\assets\` | The copies of your pictures, audio and clips (for files added with **Copy into the project**) |
| ...`\thumbs\` and `\proxies\` | Small previews. The app can make these again, so they are safe to lose |
| ...`\renders\` | Your drafts and finals (MP4 files) |
| ...`\exports\` | Your export folders |
| `.trash\` | Projects you deleted (until you delete them forever) |
| `.app-profile\` | The private settings of the app's own window. Not your normal Edge. Safe to ignore |
| `index.sqlite` | A quick project list. Rebuilt automatically if lost |

Folders that start with a dot may be hidden. In File Explorer choose **View, Show, Hidden items** to see them.

Only one StoryMotion window can use a workspace at a time.

#### Use a different folder

To keep projects somewhere else (for example a bigger drive), set the Windows environment variable `STORYMOTION_WORKSPACE`:

1. Press the **Start** button, type `environment variables` and open **Edit environment variables for your account**.
2. Under **User variables**, click **New...**.
3. **Variable name:** `STORYMOTION_WORKSPACE`. **Variable value:** the folder, for example `D:\StoryMotion Projects`.
4. Click **OK** twice, then close StoryMotion and start it again.

Your existing projects stay in the old folder. Move the old workspace's contents across (with the app closed) if you want them in the new place.

#### Projects, archive and trash

- **Rename** and **Duplicate** do what they say. **Duplicate** is a good way to try something risky.
- **Archive** hides a project from the main list without deleting anything. Tick **Show archived projects** to see it, and click **Unarchive** to bring it back.
- **Delete** asks first, then moves the project to the **Trash**. Nothing is erased yet. Open **Trash (n)** on **Your projects** and click **Restore** to bring a project back.
- **Delete forever...** in the Trash permanently erases a project and its imported files. You must type the project name to confirm. It cannot be undone.

#### Backups

StoryMotion saves automatically, but a computer can fail. A simple, safe backup:

1. Close StoryMotion (so no work is half-written).
2. Copy the whole `StoryMotion Studio` folder to a USB drive or a cloud-synced folder.
3. Do this after every working session, or at least weekly.

To restore: close the app, put the folder back in the same place (or point `STORYMOTION_WORKSPACE` at it).

If you only want to keep the results, copy your finished `-final.mp4` files (see "Make your first video", Step 9) and your **Export independent assets** folders.

If you used **Link to the original** for some files, those originals stay where they are and must be backed up as well.

### Update to a new version

1. **Back up** your workspace first (see above).
2. Download the new zip from the **Releases** page and extract it into a **new** folder (do not extract over the old one).
3. Close StoryMotion, then start the new version from its own `StoryMotion Studio.vbs`. Use **Add Desktop Shortcut.vbs** again if you want the Desktop shortcut to point to the new folder.
4. Open your projects. They are picked up automatically because they live in your workspace. If a project was made by an older version, the app updates it and keeps the original file next to it, and a message tells you.
5. When you are happy that everything works, delete the old app folder.

### Uninstall

1. Close StoryMotion.
2. Delete the Desktop shortcut **StoryMotion Studio** if you made one.
3. Delete the app folder (the one that contains `StoryMotion Studio.vbs`). Send it to the Recycle Bin, then empty it if you wish.
4. **Optional, and permanent:** to remove your projects too, delete `C:\Users\<your name>\StoryMotion Studio`. Do this only if you no longer need them, or after you have made a backup.

The app has no installer. As far as we know it does not add anything to the Windows registry, Start menu or settings, and nothing else needs removing. If you set `STORYMOTION_WORKSPACE` or `STORYMOTION_BROWSER`, you can delete those variables in the same place where you created them.


## Troubleshooting

Find the line that matches what you see, then follow the fix. Nothing here needs a terminal unless it says so.

### First, the troubleshooting launcher

If the app will not start or you do not know why, double-click **`Run with console (troubleshooting).bat`** in the app folder. It opens a black window, runs a self-check, starts the app and **keeps the messages on screen**. Read the last lines: they usually say what is wrong. Close the black window when you are done (press any key when asked).

#### Smart App Control blocked a file

Smart App Control is an optional Windows 11 protection. When it is **On**, it blocks programs that are not signed. The app's own launcher parts (Microsoft Edge, Windows Script Host and the standard Python) are signed. The bundled `ffmpeg.exe` is not signed by Microsoft, so on a computer with Smart App Control **On**, it may be blocked. This has **not yet been tested on a computer with Smart App Control turned on**, so if you see this, we would like to hear about it.

Your options, safest first:

1. Try on another computer that does not have Smart App Control on.
2. Ask your administrator or IT person.
3. Switch Smart App Control to **Evaluation** or **Off** under **Windows Security, App and browser control, Smart App Control settings**. **Be aware:** once turned off it cannot be turned on again without reinstalling or resetting Windows. This guide does not recommend it unless you understand that trade-off.

### Disk space

Videos, previews and exports are large. The **Setup check** warns when the drive holding your workspace has less than 5 GB free.

To make room:
1. Delete old drafts you no longer need from `...\projects\p-...\renders` (File Explorer, with the app closed).
2. Delete exports you no longer need from `...\projects\p-...\exports`.
3. Empty the project **Trash** (**Delete forever...**), only for projects you really do not want.
4. Move the whole workspace to a bigger drive (see "Where your files go").
5. Use **Link to the original** instead of **Copy into the project** for very large clips.

### Very long folder paths

Windows can fail on very long folder paths (about 260 characters). If extraction or the app complains about a path or "file name too long", extract the app to a short place such as `C:\Apps` and keep your project and file names reasonably short.

## Questions and answers, and glossary

### Frequently asked questions

#### Is my work private? Does anything get uploaded?
Nothing is uploaded. The app runs only on your computer, listens only to your own computer, and makes no internet connections. There are no accounts, no tracking and no crash reports. Your pictures, script and narration stay in your workspace folder. The only time anything leaves is when **you** hand an export to someone else.

#### Does it work offline?
Yes, completely. You need the internet only to download the zip. Writing, importing, previewing, rendering and exporting all work with the network off.

#### What does it cost?
The app is free to download and use. It has no cloud features in this version, so there are no usage charges. (A budget system for future paid AI services is planned but not active; nothing can spend money today.)

#### Do I need to install Python, FFmpeg or anything else?
No. Everything is inside the folder. It does not change any Python you already have.

#### Does it need administrator rights?
No. Extract it anywhere you can write to, such as `C:\Apps` or **Documents**.

#### Will it work on my computer?

| | |
|---|---|
| Windows 10 or 11, 64-bit | Yes |
| Windows 7 or 8, 32-bit Windows, Mac, Linux, phones | No |
| Microsoft Edge present | Needed (it comes with Windows 10 and 11) |

#### What video do I get?
A standard MP4 (H.264 video with AAC audio), which plays in Windows, on phones and on video sites. Final renders use the project's size, normally 1920 x 1080 at 24 frames per second (the app has no screen for changing this yet). Drafts are smaller (640 x 360) on purpose.

#### How long can a video be?
The design target is 3 to 5 minutes per episode, and it has been rehearsed at about that size. Longer videos may work but are not yet tested.

#### Which files can I import?
Pictures: PNG, JPG, WebP. Audio: WAV, MP3, AAC. Video: MP4, MOV. See "Make your first video".

#### What is a draft and what is a final?
A **draft** is a quick, small preview with a "DRAFT" badge to check timing and motion. The **final** is the full-size video. See the glossary below.

#### Is it finished software?
It is an early release (version 0.1.0). The core path (import, storyboard, draft, final, export) is built and automatically tested, but it has not yet been tried on a brand-new computer by a first-time user, and a few features are marked "not available yet" in this guide. Please report anything surprising.

#### Who owns what I make?
You do. The only mark StoryMotion adds is the "DRAFT" badge on drafts. You are responsible for having the rights to the pictures, voice and music you put in.

#### Software licences
StoryMotion Studio includes other free software. The most important: **FFmpeg 9.0.2** (video tool, **GPL v3 licence**), Python (PSF licence) and others. The full list and licence texts are in the `licenses` folder inside the app folder, in `THIRD_PARTY_NOTICES.md`. FFmpeg runs as a separate program. If you need FFmpeg's source code, see the links in that notice.

#### Why does Windows warn me about it?
The app is not "code-signed". Signing costs money each year, and it has not been bought yet. The warnings (SmartScreen and similar) are about the missing signature, not about anything found in the file. See "Download and install" and "Troubleshooting" for exactly what to click.

#### Can two people use it at once?
Not on the same projects folder at the same time. Each computer has its own workspace. To work on one project on two computers, copy the project folder (after closing the app) rather than sharing a live folder.

#### Can I move my projects to another computer?
Yes: close the app and copy the whole `StoryMotion Studio` workspace folder to the same place on the other computer. If you used **Link to the original** for some files, copy those originals too and use **Relink...**.

### Glossary

| Word | Plain meaning |
|---|---|
| **Project** | One story or episode: its script, pictures, clips, narration, storyboard and finished videos |
| **Workspace** | The folder on your computer that holds all your projects. Normally `C:\Users\<you>\StoryMotion Studio` |
| **Media** (or asset) | Any file you imported: a picture, a sound or a video clip |
| **Library** | The list of all media in a project (on the **Media** tab) |
| **Storyboard** | The plan of your video: scenes, each made of shots, timed against the narration |
| **Scene** | A part of the story, for example "Jonah boards the ship". A scene holds one or more shots |
| **Shot** | One continuous piece of the video: one picture (or clip) shown for a set time, with an optional camera move and a transition |
| **Narration** | The recorded voice of the story. It is the **narration clock**: the master timeline that every shot is measured against |
| **Narration clock** | The timeline set by the length of your narration file. All times in the Storyboard are milliseconds (ms) on it. 1000 ms is 1 second |
| **Animation mode** | How a shot is made: **STATIC** (still), **CINEMATIC** (camera move), **LAYERED** (moving cut-outs), **RENDERED** (a video clip you supply), **GENERATIVE** (AI clip; not available in this version) |
| **Motion preset** | A ready-made camera move for CINEMATIC shots, such as `slow-push-in` or `pan-left` |
| **Transition** | How one shot changes to the next: **Cut** (instant), **Crossfade (dissolve)** (blend), **Dip to black** |
| **Layer** | A separate picture with a transparent background (a character or object) that moves over a shot's background picture |
| **Music bed** (or ambience) | Background audio that plays under the narration and is lowered ("ducked") while the narrator speaks |
| **Draft render** | A small, quick (640 x 360) preview with a "DRAFT" badge, for checking timing and motion. Not final quality |
| **Final render** | The full-size finished MP4 video |
| **Proxy preview** | A smaller stand-in copy used for quick previews (the **Scrub** picture and the draft). It is for checking, not for judging quality; the final render is the real thing |
| **Export** | A folder with your shots, audio and timelines for editors or AI, written on your computer. Not the same as rendering the video |
| **Checksum** | A fingerprint of a file. If the file changes at all, the fingerprint changes |
| **Unblock** | A Windows option that tells Windows that a file you downloaded is safe to open normally |
| **SmartScreen** | A Windows feature that warns about downloads it does not recognise |
| **Smart App Control** | An optional Windows 11 protection that only allows signed programs |
| **FFmpeg** | The free video tool inside the app that actually builds your video |
